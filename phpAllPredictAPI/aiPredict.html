🤖 1. Claude Pattern + Multi-Signal
Claude/candleAnalyzerClaude.php
💡 แนวคิดหลัก (Core Concept)
Pattern Recognition & Signal Consensus: ใช้วิธีรวบรวมคะแนนโหวตระหว่างสัญญาณฝั่งกระทิง (Bullish) และฝั่งหมี (Bearish) จาก 4 มิติ เพื่อหาความน่าจะเป็นสุทธิ
⚙️ 4 ปัจจัยที่ใช้คำนวณ
  • 1. Patterns
    Candlestick Patterns: ตรวจสอบรูปแบบแท่งเทียนแท่งล่าสุด
    • +Bullish: Hammer, Morning Star, Bullish Engulfing, Piercing Line
    • +Bearish: Shooting Star, Hanging Man, Evening Star, Bearish Engulfing
  • 2. EMA
    EMA3 & EMA5:
    • ถ้า EMA(3) > EMA(5) ➔ +Bullish | อื่นๆ ➔ +Bearish
    • ถ้า Close > EMA(3) ➔ +Bullish | อื่นๆ ➔ +Bearish
  • 3. Bollinger
    Bollinger Bands (20, 2):
    • Overbought / Oversold: ถ้า Close < Lower Band ➔ +Bullish (มองการเด้ง Reversal) | ถ้า Close > Upper Band ➔ +Bearish
    • Mean Reversion: ถ้า Close > Middle Band ➔ +Bearish (แรงดึงกลับ) | ถ้า Close < Middle Band ➔ +Bullish
  • 4. Trend
    Overall Trend (10 Bars): นับจำนวนแท่งเขียวเทียบแท่งแดง 10 แท่งล่าสุด
    • ถ้าแท่งเขียวมากกว่า ➔ +Bullish | ถ้าน้อยกว่า ➔ +Bearish
📐 สูตรการตัดสินใจ (Decision Rule)
Bullish% = (BullishSignals / TotalSignals) × 100
Bearish% = (BearishSignals / TotalSignals) × 100
ผลลัพธ์: 🟢 Green (CALL) เมื่อ Bullish% > Bearish% 🔴 Red (PUT) เมื่อ Bearish% >= Bullish%
💬 2. ChatGPT Momentum Score Adjustment
Chatgpt/candleAnalyzerChatGPT.php
💡 แนวคิดหลัก (Core Concept)
Technical Momentum Scoring: เริ่มต้นด้วยความน่าจะเป็นเท่ากันที่ Base 50% Green / 50% Red จากนั้นนำอินดิเคเตอร์เชิงโมเมนตัมมาปรับเพิ่ม/ลดความน่าจะเป็น
⚙️ กฎการปรับคะแนน (predictNextCandle)
อินดิเคเตอร์ เงื่อนไข การปรับคะแนนความน่าจะเป็น
RSI (14) RSI > 70 (Overbought)
RSI < 30 (Oversold)		 Red +20% / Green -20%
Green +20% / Red -20%
MACD (12, 26, 9) MACD Line > 0
MACD Line <= 0		 Green +15% / Red -15%
Red +15% / Green -15%
Stochastic RSI (14) Stoch RSI > 80
Stoch RSI < 20		 Red +10% / Green -10%
Green +10% / Red -10%
ADX (14) ADX > 25 (ยืนยันเทรนด์แข็งแรง) ขยายแต้มต่อ +10% ให้ฝั่งที่มีน้ำหนักนำอยู่
ผลลัพธ์: 🟢 Green (CALL) เมื่อ Probability Green > Probability Red 🔴 Red (PUT) เมื่อ Probability Red >= Probability Green
🔍 3. DeepSeek Weighted Quantitative Multi-Factor
DeepSeek/CandlestickAnalyzer_DeepSeek.php
💡 แนวคิดหลัก (Core Concept)
Weighted Quantitative Scoring: คำนวณ 7 ปัจจัยสำคัญโดยมีค่าน้ำหนัก (Weight) แต่ละตัวกำกับอย่างชัดเจน รวมเป็น Total Score แล้ว Clamp ไว้ที่ 15% - 85%
⚙️ 7 ปัจจัยและค่าน้ำหนัก (Weights)
ปัจจัย น้ำหนัก เกณฑ์คะแนนย่อย
1. Trend Analysis × 1.5 Strong Uptrend (+1.5), Moderate (+1.0), Strong Downtrend (-1.5), Moderate (-1.0)
2. Recent 3 Candles × 0.8 อัตราส่วนสีเขียว/แดง ใน 3 แท่งล่าสุด (-1.0 ถึง +1.0)
3. Bollinger Bands × 1.2 Close < Lower (+1.2 Rebound), Close > Upper (-1.2 Rejection)
4. EMA Crossover × 1.0 EMA3 ตัดขึ้น EMA5 (+1.2), EMA3 ตัดลง EMA5 (-1.2)
5. RSI (14) × 1.3 < 30 (+1.5), > 70 (-1.5), > 50 (+0.5), < 50 (-0.5)
6. ADX Trend Strength × 1.1 ถ้า ADX > 25: หากแนวโน้มขึ้น (+1.0), หากแนวโน้มลง (-1.0)
7. Ichimoku Cloud × 1.4 Bullish Cross / Above Cloud (+1.5), Below Cloud (-1.5), Inside Cloud (-0.5)
TotalScore = ( Σ (Factor × Weight) ) × 5
GreenProbability = Clamp(50 + TotalScore, 15%, 85%)
RedProbability = 100 - GreenProbability
ผลลัพธ์: 🟢 Green (CALL) เมื่อ GreenProbability > RedProbability 🔴 Red (PUT) เมื่อ RedProbability >= GreenProbability
📈 4. NoSort Sequential Microstructure Rules
ClsTrade/noSortGetAction.php
💡 แนวคิดหลัก (Core Concept)
Sequential Rule Engine: ตรวจสอบเงื่อนไขตามลำดับขั้นตอนธรรมชาติ (Step 1-1, Step 1-2, ...) กว่า 1,700 บรรทัด โดยประเมินจากการเคลื่อนไหวระดับ Pip และทิศทางความชัน EMA3 พื้นฐาน
⚙️ กลไกการตรวจสอบ
  • Step 1
    ตรวจทิศทาง Slope EMA3: ถ้าความชันลง (Down) ➔ ตั้งต้นที่ PUT (Red) | ถ้าขึ้น (Up) ➔ ตั้งต้นที่ CALL (Green)
  • Step 2
    วิเคราะห์ Microstructure: ตรวจสอบ pipSize, delTapip, อัตราส่วนเนื้อเทียนและไส้เทียน
  • Step 3
    ตรวจจับการบรรจบ MACD: พิจารณา MACDHeight และการลู่เข้า/ถ่างออก (Convergence / Divergence)
ผลลัพธ์: 🟢 Green เมื่อ Action == 'CALL' 🔴 Red เมื่อ Action == 'PUT'
📊 5. WithSort Sorted Specificity-First Tree
ClsTrade/sortGetAction.php
💡 แนวคิดหลัก (Core Concept)
Priority / Specificity-First Decision Tree: จัดเรียงลำดับเงื่อนไขใหม่ โดยนำ เคสที่มีเงื่อนไขจำเพาะสูงสุด (7-8 เงื่อนไข) มาตรวจสอบก่อน เมื่อตรงกับเงื่อนไขใด จะ Early Exit (ส่งผลลัพธ์ทันที) ทำให้แพทเทิร์นพิเศษไม่ถูกกฎทั่วไปกลบ
⚙️ ลำดับความสำคัญของกฎ (Priority Order)
  • ลำดับ 1: High Specificity (7 เงื่อนไข)
    ตรวจประวัติการกลับตัวย้อนหลัง 4 แท่ง (PreviousTurnTypeBack1..4) ร่วมกับ emaConflict (เช่น 53G, 35R), ความชัน abs(ema3SlopeValue) < 5, และ MACDConvergence ➔ Return ทันที!
  • ลำดับ 2: Medium Specificity (4-6 เงื่อนไข)
    ตรวจสอบจุดตัดราคา CutPointType และการยืนยันโมเมนตัม
  • ลำดับ 3: General Cases (1-3 เงื่อนไข)
    หากไม่ตรงกับเคสพิเศษข้างต้น จึงค่อยใช้เกณฑ์ความชันและทิศทางทั่วไป
ผลลัพธ์: 🟢 Green เมื่อ Action == 'CALL' 🔴 Red เมื่อ Action == 'PUT'
⚖️ 6. ตารางเปรียบเทียบจุดเด่นของแต่ละโมเดล
โมเดล สไตล์การวิเคราะห์ จุดเด่น สภาวะตลาดที่เหมาะสม
