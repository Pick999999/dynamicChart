❓ แก้ปัญหา:
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

ปัญหา: ไม่แสดง VPS
→ ตรวจสอบตาราง vpsMaster มีข้อมูลหรือไม่
→ เช็ค http://localhost/php/api_vps.php

ปัญหา: Error 404
→ VPS ไม่มี API endpoint /api/export_trade_data
→ ตรวจสอบ URL/IP ของ VPS

ปัญหา: Error 500
→ PHP ไม่สามารถดาวน์โหลดได้
→ ตรวจสอบ cURL extension
→ ดู error.log ใน C:\xampp\apache\logs\

ปัญหา: CORS Error
→ ไม่ควรเกิด (ใช้ PHP backend แล้ว)
→ Clear cache และรีเฟรช
