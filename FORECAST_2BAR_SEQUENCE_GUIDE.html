01 1. ภาพรวมและแนวคิด (Overview & Core Concepts)

การวิเคราะห์แท่งเทียนแบบแท่งเดียวโดดๆ (Single-Bar Analysis) มักจะเจอปัญหา "สัญญาณหลอก (False Signals)" หรือติดกับดักราคา (Bull/Bear Traps) เนื่องจากไม่ทราบว่า "แรงของแท่งก่อนหน้าถูกส่งต่อมาอย่างไร"

⏳ แท่งก่อนหน้า (t - 1)

ดูสภาวะที่เกิดขึ้นก่อนหน้า เช่น เกิด Inside Bar สะสมพลัง, เกิด Bull Trap หลอกซื้อ, หรือเป็นแท่ง Breakout พุ่งแรง

⚡ แท่งปัจจุบัน (t)

ดูพฤติกรรมตอบสนองของแท่งปัจจุบันว่า ยืนยัน (Confirm), ปฏิเสธแรงเดิม (Reject), หรือทะลุกรอบแนวรับแนวต้าน (Breakout)

🎯 ผลลัพธ์: เมื่อนำข้อมูลทั้งสองแท่งมาร้อยเรียงกันเป็น "คู่รหัส (Transition Pair)" จะทำให้เข้าใจแรงส่งของโมเมนตัมและจิตวิทยาตลาดได้อย่างแม่นยำสูงสุด

🎯 Tier 1: EXACT_RULE (แม่แบบตายตัว)
  • จับคู่กับพฤติกรรมที่มี Win Rate ชัดเจนทางสถิติ
  • ระดับความมั่นใจ: HIGH ถึง MAX
  • คะแนนความน่าจะเป็น: 80% – 95%
  • เช่น Inside Bar Breakout, Exhaustion Spike, Trap Confirmation
⚡ Tier 2: DYNAMIC_TRANSITION (คำนวณพลวัต)
  • ครอบคลุมทุกคู่รหัสที่เหลือใน 729 แบบโดยอัตโนมัติ
  • วิเคราะห์ Trend หลัก + สีแท่งเทียน + การชะลอตัว (Hesitation)
  • คะแนนความน่าจะเป็น: 50% – 68%
  • ช่วยให้ระบบไม่หยุดทำงานเมื่อเจอกราฟรูปแบบแปลกใหม่

06 6. ระบบ Dynamic Transition (รองรับทุกคู่ใน 729 แบบ)

กรณีที่คู่รหัสนั้นไม่ได้อยู่ในตาราง SEQUENCE_RULES ระบบจะใช้ตรรกะแบบ Dynamic Transition ในการอนุมานทิศทางและให้คะแนนแบบอัตโนมัติ:

JavaScript — predictNextCandle.js Dynamic Transition Fallback Logic 
if (currTrend.trend === 'UpTrend') {
  if (currIsBullish) {
    // โครงสร้างขึ้น + แท่งปัจจุบันเขียว
    action = 'CALL'; confidence = 'MEDIUM'; score = 68;
    patternName = 'UpTrend Momentum (' + pCodeNo + '➔' + cCodeNo + ')';
  } else {
    // โครงสร้างขึ้นแต่แท่งปัจจุบันปิดแดง (ลังเล)
    action = 'WAIT'; confidence = 'LOW'; score = 55;
    patternName = 'UpTrend Hesitation (' + pCodeNo + '➔' + cCodeNo + ')';
  }
} else if (currTrend.trend === 'DownTrend') {
  if (!currIsBullish) {
    // โครงสร้างลง + แท่งปัจจุบันแดง
    action = 'PUT'; confidence = 'MEDIUM'; score = 68;
    patternName = 'DownTrend Momentum (' + pCodeNo + '➔' + cCodeNo + ')';
  } else {
    // โครงสร้างลงแต่แท่งปัจจุบันปิดเขียว (ลังเล)
    action = 'WAIT'; confidence = 'LOW'; score = 55;
    patternName = 'DownTrend Hesitation (' + pCodeNo + '➔' + cCodeNo + ')';
  }
} else {
  // สภาวะ Sideways หรือไร้ทิศทาง
  action = 'WAIT'; confidence = 'MEDIUM'; score = 60;
  patternName = 'Sideways/Transition (' + pCodeNo + '➔' + cCodeNo + ')';
}

07 7. ระบบคัดกรอง Gatekeeper (isSelectedToAction)

ในหน้าจอ index_short_term.html มีระบบ Gatekeeper เพื่อตรวจสอบสิทธิ์ความปลอดภัยก่อนที่จะอนุญาตให้ระบบเข้าทำออเดอร์จริง:

🔴 เมื่อ isSelectedToAction === 'n'

บังคับตัดเป็น IDLE (ข้ามการเทรด) ทันที แม้ผลลัพธ์ของ Sequence Engine จะวิเคราะห์ได้ CALL หรือ PUT ก็ตาม เพื่อป้องกันการเทรดในรหัสแท่งเทียนที่ผู้ใช้งานตั้งใจปิดใช้งาน

🟢 เมื่อ isSelectedToAction === 'y'

อนุญาตให้ออก Action จริง โดยนำผลลัพธ์ที่คำนวณได้ (CALL / PUT / WAIT) ส่งต่อไปยังระบบวางออเดอร์อัตโนมัติ
